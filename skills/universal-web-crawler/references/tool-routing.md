# Evose 工具选择与接入

2026-10-15 已收到用户《Evose 工具能力目录》，并只读查看 Evose 工具市场。目录说明第三方产品的全部能力未必开放；以下是选型和接入要求，不是已完成的绑定。

## 最小配置

| 市场卡片名称 | 何时选择 | 必须核对的真实能力 | 缺失时处理 |
|---|---|---|---|
| Firecrawl 或 Firecrawl 网页抓取 | 指定 URL 的默认采集入口；二选一 | URL 输入、内容输出、源站状态；按任务再核查结构化提取、HTML/links、渲染、map/crawl、作业查询/结果分页、缓存参数 | 能读单页就用观察到的导航逐页；不能声称具备整站 crawl |
| Exa Search / Tavily 搜索 / DuckDuckGo Search | 未知入口、寻找公开 feed 或目标栏目；只选一个 | 查询、来源 URL、结果范围；正文是否真的抓取 | 已给 URL 时不必挂搜索；搜索片段不能当作原始记录 |
| Browserbase | 数据需要点击、滚动、翻页或会话 | 除创建会话外还需导航、读取/提取、交互及结束会话；网络请求/响应体能力另核查 | 只有会话管理就不能完成浏览器采集；使用已有渲染抓取或报告缺口 |
| Apify | 通用路线不适用，已有 Actor 匹配网站和对象 | Actor 输入/输出契约、维护与适用范围、运行状态、dataset 读取/分页、预算 | 未匹配不盲目启动；run 成功后还需取回并验证数据 |
| 对应 TikHub 工具、其他站点数据工具 | 目标是其覆盖的平台实体 | ID/URL 对应、字段、日期/地区、分页游标与授权范围 | 第三方覆盖不等于目标网站全量；保留来源和缺口 |
| Google Sheets / 飞书表格 / Lark 表格 / 云文档 | 用户要求持久交付且给定目的地 | 写入范围、字段格式、读回核对与记录链接 | 无存储工具时交付可复制 JSON/CSV/Markdown |

起步只需要一项真实 URL 读取能力。按任务增加搜索或交互，通常 1–3 个工具包即可；不默认挂全部市场工具。E2B、REA、客户端 SDK 和 CLI 不属于本版本运行要求。

## 已观察与尚未验证

在 `AI CMO` 空间的市场搜索结果中：`Firecrawl` 内置卡片显示 **6 个工具**；`Firecrawl 网页抓取` 显示 **2 个工具**，在两个分类重复展示。`Browserbase` 显示 **18 个工具**，说明列举的是会话、context、项目、扩展、日志、调试 URL 和下载文件元数据管理，尚无页面导航/点击/提取的证据。因此不能将这个卡片直接当成 Browserbase 官方完整浏览器 MCP。

这里只证实卡片存在、显示数量和说明；没有打开具体方法定义，不能列出方法名、认定支持 RSS/XML，或断言工具较多的卡片一定更好。空间、Agent 与工具实际绑定尚未完成。市场包不是本机 Codex Firecrawl connector；本机研究调用不能计作 Evose 平台测试。部署位置按用户指定的空间执行。

## 绑定后检查

1. 在 Agent 工具选择/详情中读取真实方法名、说明、必填参数和返回结构。每条路线只保留相关方法；不得用官方 REST/CLI 名称替代平台工具名。
2. 调试一次公开页面，在 Trace 核对实际方法、输入 URL、原始返回、源站状态及来源；不要输出 Token、Cookie 或授权头。
3. 若任务使用分页/异步作业，实际验证相邻页/游标、终态、结果 next 和错误页；返回缺失时报告能力限制。
4. 若要求最新数据，验证实际新鲜度或缓存年龄。Markdown 中的采集时间不证明源页面新鲜。
5. 若输出到表格/文件，核对数量、字段、可访问地址以及实际保存结果。未保存时直接提供文本。

零依赖指交付资产只有 Markdown，不安装包/脚本/MCP；宿主网页访问、模型、服务账号和费用仍需真实配置。市场能力缺失无法靠提示词补齐。
