## 仍需保留的限制

1. 109 行清单完成了逐项对照与入口探测，未逐页全量重采所有信源。HTML/RSS 的菜单枚举和历史翻页仍需站点级完整性验收；有样本不等于全站可采。
2. 3 个 WordPress 信源类型探测失败；部分其他类型仍需判定是否为内容或模板。`--check-types DOMAIN` 会显式列出未配置类型，不会静默视为已覆盖。
3. Palau media 计数矛盾仍未解释；MECDM 有效入口未确认；既有停放/改站记录保留，不将网络失败判死站。
4. 数据写入的普通异常已有回滚与重跑测试，但 JSONL 和 URL 文件之间遭遇 SIGKILL/断电的事务保证未完成；本轮不宣称严格 exactly-once。
5. 原有 LNC、Samoa Observer 长进程没有中断或热替换；它们在下一次启动时才加载本轮修复。本轮补采与验证均使用新代码。
6. 未全量替换历史正文、未清空数据、未开启新的付费代理服务，也未创建或部署 Agent。

本轮优先修复实测缺陷，复用现有 trafilatura、lxml、请求队列、游标与浏览器适配器，没有为采用技术栈清单而另建采集框架。人工选择出口后的单站成功，只记录为该次验证成功。
