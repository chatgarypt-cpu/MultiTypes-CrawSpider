## Server 0.3.0

- 网页任务支持「加入长期采集」。沿用现有正式配置或保存已探测规则，按 URL 合并已采内容，并交由 Supervisor 接续待采链接。
- 站点监控可批量刷新核对和补采。主表显示简短的失败原因，任务详情保留原始错误。
- CentOS 8.4 x86_64 安装包通过 Podman 运行网页服务与 Supervisor。正式信源保存在数据卷，安装脚本支持迁移旧容器中的站点清单。
- 发布包提供空白信源模板。

下载服务器源码包和 `SHA256SUMS`，校验并解压后执行 `sudo bash deploy/centos8/install.sh`。配置和升级说明见包内的 `README.md`。
